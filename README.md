# Web Development Course

This repository contains exercises, practical activities, and projects developed for the **Web Application Development** course at the State University of Santa Catarina (UDESC).

The repository documents the learning process throughout the semester, covering the fundamentals of web development and the integration of front-end and back-end technologies.

## Technologies

- **HTML5** — Page structure, semantic elements, forms, and multimedia.
- **CSS3** — Styling, layouts, responsive design, and visual customization.
- **JavaScript** — Client-side interactivity, form validation, event handling, and DOM manipulation.
- **PHP** — Server-side programming, form processing, sessions, cookies, and authentication.
- **MySQL** — Database creation, SQL operations, and data management.
- **Bootstrap and other CSS frameworks** — Layout development and reusable components.

## Course Exercises

The repository is organized around the practical activities completed during the course.

| Exercise | Topics |
|---|---|
| 01 | HTML fundamentals: text, images, and links |
| 02 | HTML lists, tables, and forms |
| 03 | HTML5 semantic elements, form attributes, multimedia, Canvas, and SVG |
| 04 | Introduction to CSS |
| 05 | CSS selectors, classes, IDs, and styling methods |
| 06 | Page layouts and CSS frameworks |
| 07 | JavaScript fundamentals, forms, and date and time handling |
| 08 | JavaScript functionality, validation, strings, arrays, dates, and events |
| 09 | PHP fundamentals, functions, counters, cookies, and sessions |
| 10 | PHP forms, input validation, authentication, and password hashing |
| 11 | MySQL databases and SQL operations |
| 12 | PHP and MySQL integration for CRUD operations |

## Learning Objectives

- Build web pages using HTML5.
- Apply CSS to create structured and visually consistent layouts.
- Add interactivity using JavaScript.
- Develop server-side functionality with PHP.
- Create and manage relational databases using MySQL.
- Validate and process user input.
- Implement CRUD operations: Create, Read, Update, and Delete.
- Integrate front-end and back-end technologies into web applications.

## Getting Started

Most HTML, CSS, and JavaScript exercises can be run directly in a web browser.

For PHP and MySQL exercises, a local development environment with PHP and a MySQL-compatible database is required. Tools such as XAMPP or a separately configured Apache, PHP, and MySQL environment can be used.

1. Clone the repository:

   ```bash
   git clone https://github.com/ana-athayde/web-development-course.git
   ```

2. Navigate to the project directory:

   ```bash
   cd web-development-course
   ```

3. Open the relevant HTML file in your browser, or configure a local server to run the PHP exercises.
